## Vector Tree

The representation of a tree using vectors of values, parent indices, and left-sibling indices is inspired by material by Aaron W. Hsu:

* "High-performance Tree Wrangling, the APL Way", Dyalog '18:
  <https://www.youtube.com/watch?v=hzPd3umu78g>

* "A Data Parallel Compiler Hosted on the GPU",
  диссертация, Indiana University, 2019:
  <https://hdl.handle.net/2022/24749>

This module explores these ideas using Haskell, the ST monad, and the Vector library.
